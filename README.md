## Lab Questions

### In plain English describe the function and use of a multiplexer.

A multiplexer takes many inputs and using a selector chooses which input to send to the output.

### In plain English describe the function and use of a demultiplexer.

A demultiplexer takes an input and uses a selector to choose what output it should send the input to.
